0. 使用说明

0.1 能力基准与单日口径

基准（本队实测）：峨眉山南线（99 道拐）24km / 累计爬升 ~3000m / 9–10 小时完成 → 爬升速度 300–330m/h、综合速度 ~2.5km/h（石阶路面）。"单日"：徒步时间在一个日历日内完成（开走→登顶→出山）；前一天交通/住宿就位是允许且标准的玩法。校准锚点为双线制（v7）：峨眉山南线（爬升主导型，125 m/km）+ 杭州标毅线（距离主导型，60 m/km，§2.10）——两类负荷形态各有一个实测锚点，速度模型才被双向钉住。

0.2 强度模型 v2：技术难度分级 × 爬升密度（v6 修订）

v5 曾用"野路一律打 7–8 折"——本版修正："野路"不是均质类别。轨迹证据显示成熟野路（路迹清晰+飘带/路牌密集）可以比万级石阶更快：宜兴标准环 65% 竹林"野路"，轨迹中位速度 3.2–3.3 km/h 为全线最高；武功山龙山→发云界"野路"段路牌密集"绝对不会走错路"，强驴 2.5–3.5h 通过；白马尖南线古道"很好走、路径清晰"。真正慢的是 T4 受阻段（乱石翻行/滑坡体/60°+ 陡坡手脚并用/需自主寻路），如白马尖天河尖方向（"很多段几乎看不见路，在大石头上翻行"）、九华山打鼓岭石海。正确因子是"路面技术等级 × 爬升/下降密度"：

0.4 版本勘误记录

v5 勘误：v4 强度列误用爬升占比口径 → v5 改时间口径重算。
v6 勘误（轨迹校准后）：① 白马尖双环 13–14.5h→13–15h，强度 1.4×+，单日降级为不可行——商业队轨迹明确拆两日（D1 15km/8h + D2 13km/7.5h），且无任何单日完成样本；改推单环（0.7×）/折中版（1.05×）/驮锅雷（0.65×）；② 千八龙泉段 8–10h→9–10.5h（1.0×）（九峰轻装轨迹中位 2.5–2.7 km/h 反推）；③ 小千八 6–8h→7.5–9h（0.85×，低置信）；④ 宜兴标准环 6–8h→7–8.5h（0.8×）、小飞象 9–11h→10–11.5h（1.15×）；⑤ 黄山 11–13h→12–14h（1.35×）——分段合成：前山含天都 5.5–6h + 中段 1.5–2h + 峡谷 2h + 地轨 + 后山 2.75–3.25h + 休整 1.5h；去天都版 10.5–12h（1.15×）；⑥ 武功山正穿半程 8–10h→8–9h（0.9×）（沈子村→金顶 GPS 4h30 实证）；⑦ 九华后山环线 5–7h→5–6.5h（0.6×）；⑧ 九华速穿 11–13h→11.5–13.5h（1.3×）（南脊野线 6.8km/近 6h 轨迹锚定 + 攻略汇总 12–14h 佐证）。武功山反穿（24 样本）/武明 B 线/三清山/明月山经轨迹检验维持。
方法论结论（回应本轮修正意见）：徒步速度的第一决定因素是爬升密度（m/km）× T4 级受阻段占比，而非"野路 vs 石阶"标签——宜兴 65% 竹林"野路"轨迹速度全线最高（成熟路迹+75m/km 中等密度）；白马尖名义爬升不大但天河尖方向 T4 乱石段拖垮速度；黄山/三清山纯 T1 石阶却因双向升降负荷（黄山 ↑2100+↓2200）回到 1.3×。

为什么单列：①2002 年仿香港毅行者设计的"标准毅行"线，"杭州徒步毕业线"，本地强驴认证线；②校准价值——爬升密度仅 60m/km（距离主导型），与峨眉山锚（125m/km 爬升主导型）互补，是速度模型在"长距离低爬升"形态下的本地参照；③地铁直达起终点、可随时改线下撤，零成本高频拉练。

路线：老和云起牌坊（地铁 3 号线古荡站 B 口步行百米）→ 老和山(164m) → 秦亭山 → 将军山 → 美女山 → 灵峰山 → 北高峰 313.7m（"天下第一财神庙"，补水）→ 美人峰 → 龙门山 → 石人亭（石人岭 256m，补水）→ 白云峰 → 猢狲岭 → 天竺山 412.5m（杭州主城区最高峰）→ 十里琅珰（茶园山脊）→ 五云山 340m（补水）→ 林海亭（酒店补水）→ 贵人阁(240m，俯瞰钱塘江) → 虎跑（补水）→ 玉皇山（俯瞰八卦田）→ 将台山 → 凤凰山 → 万松书院 → 云居山 → 城隍山（吴山）→ 吴山广场（公交/地铁回程），串 20+ 山峰。

  • 数据裁定：标称主流 25km/+1500m（晚潮/搜狐/网易多源）；区间 24–26km/+1200–1570m（8264 GPS +~1200m/运动 7.5h、实测帖 ~25km/+1570m）；"实际走出 28km/1800m"系走错绕行个例——岔路极多，跟轨迹走
  • 路面（T 构成）："90% 以上人工铺成石板路/台阶"（两步路游记原文）→ T1 ~70–90% + T2 游步道 + 少数 T3 野路段（23 号电话亭→天竺山、天竺山→十里琅珰下、五云山→林海亭、贵人阁→儿童公园）；无 T4/T5——标毅的"野路"不构成难度项
  • 耗时（双因子+轨迹校准）：距离约束 25÷3.2≈7.8h 主导（爬升约束仅 1500÷330≈4.5h）+ 休整 → 本队 7.5–9h（0.85×）；轨迹：GPS 运动 7.5h（2025-01 个人，含拍照祈福）、常规口径 6–10h、"体力好的四小时跑完"（越野级，剔除）
  • 后勤：起点地铁直达、终点吴山广场公交/地铁——全库唯一零接驳线；补给密集（北高峰/石人岭/五云山/林海亭/虎跑/龙井村扫码水 3–5 元/梅家坞/满觉陇）→ 轻装 1–1.5L 水即可；四段划分（老和云起→北高峰→真际寺/龙井→四眼井→吴山），每段末都可下撤改线
  • 风险：岔路多（迷路即 +3–5km）；夏季中暑警示（2026-07 杭州山区中暑/失温报道，盛夏清晨出发+水量加倍）；夜爬北高峰段有摩托飙车险情报道（2026-09）；石板路对膝不友好（缓冲鞋+杖）；冬季正常可走（低海拔无冰雪问题）
  • 校准用法：每 1–2 个月走一次当"体检尺"——按 0.85× 基准对照实测：<7h 可上 1.15× 档（武功山反穿/武明纵穿/小飞象）；<6h 可挑 1.3× 档（九华速穿/黄山大环线）；新队友首次入队也用它标定个人系数
