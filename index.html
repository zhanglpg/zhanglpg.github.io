Tools & Dashboards

  • 📝 HotCRP Paper Tracker
    Personal dashboard that pulls HotCRP review-system notifications from Gmail (IMAP), groups events by (conference, paper #), and renders per-paper status — submitted, reviews received, accepted, camera-ready, award — with author lists, event timelines, update/comment/review counts, search, and per-status filters. Refreshed automatically by the 4-hour email cron.
  • 📚 Schoology Tracker
    Personal dashboard that pulls Schoology Weekly Summary emails from Gmail (IMAP), parses grades, assignments, and overdue items, and renders a color-coded view per student with sortable courses, sparkline trends from a daily snapshot history, and an activity timeline. Pipeline auto-deploys to GitHub Pages after each refresh.
  • Revenue-per-Chip-Hour Roofline Simulator
    Interactive React dashboard that maximizes per-chip total-token TPM (the policy-invariant proxy for revenue/chip-hour) under TTFT/TPOT SLOs for MoE LLMs. Six models (DeepSeek V4 Pro/Flash, Qwen 3.5-397B, Kimi K2.6, GLM 5.1, MiniMax M2.7) × six chips (B200, B300, GB300 NVL72, TPU Ironwood, TPU v8i, AMD MI355X) × four scenarios, with TPOT/TTFT/cache-hit-rate sliders, optimal-θ search, decode/TTFT breakdowns, and the precision-aware hierarchical roofline algorithm from the companion paper.
